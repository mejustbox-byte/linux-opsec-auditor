# Архитектура продукта

MVP — локальный CLI и чистая offline-оценка нормализованного JSON; HTTP API, daemon,
БД и удалённого SSH transport нет. Вход: разрешённые фиксированные чтения либо
типизированный снимок оператора. Выход: 12 findings и summary в JSON/тексте.

Поток: collector → строгая schema v1 → нормализованные facts → чистый evaluator →
ограниченное evidence → явно выбранный приватный файл/stdout. Схема закрыта для
произвольных команд, путей и текста. Runtime не использует subprocess/сетевые API.

| Модуль | Реальная ответственность | Не реализовано |
|---|---|---|
| schema.py | Типы, поля, диапазоны, UTC, повторы и лимит JSON | Общий JSON Schema engine, подписи facts |
| collector.py | OS identity, global SSH yes/no, четыре файла mode/owner, индикатор SELinux | Include/Match, ACL, sudo/PAM, package/service/remote collectors |
| rules.py | 12 ограниченных политик, стабильные ID, source/confidence, рекомендации | Полная compliance-сертификация и аттестация |
| cli.py | Команды, выбор групп, пороги, приватная новая запись | Remediation, повышение прав, автоматическая публикация отчётов |
| tools/ | Тестирование, сборка и проверка release artifacts | Аудит реальной инфраструктуры при старте |

Чтения и запись закреплены fd. Symlink, FIFO, устройства и слишком большие файлы
отвергаются. Изменяющееся содержимое и враждебное ядро не аттестуются; I/O deadline
жёстко не гарантирован. Отсутствующие/устаревшие/неподдерживаемые факты — unknown,
отключённые — not_run. Complete не означает безопасность.

Расширение возможно только через ревью источников, схемы, применимости и тестов;
никаких исполняемых policy plugins. Подробности и диаграмма — [docs](docs/architecture.md),
формальный вход/выход — [контракт](CORE-CONTRACT.md), риски — [модель угроз](THREAT-MODEL.md).
