# История изменений

## 0.1.0a2 / v0.1.0-alpha.2

- Документация, release notes, пользовательские описания правил/схем/CLI и инструкции среды на русском.
- Подготовка среды воспроизводится с новым venv и новым каталогом сборки.
- Публикация assets из проверенного tag/commit, ограниченные права Actions, проверка скачанных checksum.
- Реальные OS/kernel/LSM/restore проверки по-прежнему не выполнены; выпуск предварительный.

## 0.1.0a1 / v0.1.0-alpha.1

- Первый read-only CLI: строгий JSON, 12 групп правил, JSON/текстовые отчёты и ограниченный collector.
- Синтетические тесты, фикстуры, hash-locked сборка, wheel/sdist и CI.
- Нативные wheel/source/SHA256SUMS публикуются штатным Actions GITHUB_TOKEN.
- Исходный tag и старый выпуск сохраняются; документация в старом неизменяемом tag может быть английской.
