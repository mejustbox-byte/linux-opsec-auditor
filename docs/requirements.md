# Product Requirements and MVP

This document defines the scope, constraints, and acceptance criteria for the
Linux server security auditor, including supported distributions, read-only
evidence collection, deterministic findings, private local reports, and
synthetic validation fixtures.


## Требования

| ID | Требование | Доказательство MVP / оставшееся ограничение |
|---|---|---|
| R01 | Только чтение; без исправлений, изменения служб, пакетов и ядра | Runtime не импортирует API команд/сети; фиксированные чтения; запись только явно выбранного отчёта |
| R02 | Без sudo и повышения прав; недоступное чтение — unknown | Повышение прав отсутствует; пропущенные и недоступные источники — unknown |
| R03 | Без исполнения политик, произвольных команд и shell-подстановки | Нет subprocess в runtime; схема запрещает лишние поля |
| R04 | Версии правил, UTC, severity, evidence, причина, рекомендации и пределы | 12 групп, версии schema/policy/rule, текстовый и JSON-отчёт |
| R05 | Минимизация секретов и инфраструктурных данных | Только допустимые boolean/enum/integer; digest в отчёте заменён равенством |
| R06 | Локальный приватный вывод; без отправки в сеть | Явный путь, приватный каталог и новый файл 0600; stdout контролирует оператор |
| R07 | Ограничения входа; отказ от symlink, FIFO, устройств и обхода пути | 1 MiB JSON, 64 KiB SSH, 16 KiB ОС; nofollow и fd; жёсткого срока I/O нет |
| R08 | Различать static/runtime и утверждения operator/synthetic | source и ограничения; безопасные static-данные не дают runtime-pass |
| R09 | Правила по ОС/версии, без неявного fallback | Кандидаты: Ubuntu 22.04/24.04, Debian 12/13, RHEL 9/10, только x86_64 |
| R10 | Недоступное не равно безопасному; повреждённый документ — ошибка | unknown отдельно от not_run; exit 2 без вывода содержимого |
| R11 | Детерминизм кроме временных полей | Чистая оценка с передаваемыми часами; стабильные порядок и ID |
| R12 | Цель: 60 с и 128 MiB на эталонном хосте | На эталонном хосте не измерено; гарантии срока и памяти нет |
| R13 | Без сети на целевом хосте; проверенные датированные advisories | Только внешние нормализованные утверждения; подлинность advisories и entitlement не реализована |

Приёмка: collector не меняет охраняемую конфигурацию; отчёт не перезаписывает файл;
тесты действительно выполняются; wheel устанавливается без сети и runtime-зависимостей;
примеры синтетические. Статусы findings: pass/fail/unknown/not_run. Отдельных
not_applicable/error нет: неприменимая/неизвестная платформа даёт unknown, отключённое
правило — not_run; повреждённый документ целиком отвергается с exit 2.

## Выполненный MVP и следующие шаги

Выполнены требования/модель угроз, строгая схема, evaluator 12 ограниченных политик,
collector SSH/метаданных, приватный вывод, фикстуры и тесты, сборка с lockfile и CI.
Actions публикует проверенные assets; реальная платформенная приёмка ещё впереди.

Следующие этапы: findings по отдельным файлам; ACL и родительские каталоги; effective
SSH с Match/Include; парсеры sudo/PAM по ОС; systemd runtime; подписанные advisories
с backports; ADR SSH transport; утверждение и подпись baseline. Для каждого нужны
безопасные источники, негативные тесты и собственные доказательства применения.

Стабильный release возможен только после отдельных реальных VM-проверок каждой
заявленной версии/архитектуры. Чтение может менять atime и audit-журналы: «только
чтение» означает отсутствие конфигурационных исправлений, а не отсутствие всех эффектов.
